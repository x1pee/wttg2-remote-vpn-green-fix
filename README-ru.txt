Remote VPN Green Fix 1.1.0

Это замена существующего WTTG2_RemoteVPN_Green_BepInEx.dll с тем же GUID. Не устанавливайте обе версии одновременно.

Что изменилось
- Нет покадрового поиска placement и reflection. Объекты проверяются по таймеру раз в 1 секунду.
- Зелёный preview через MaterialPropertyBlock без создания копии Material.
- Прежнее поведение SetCurrency(120,3) сохранено по умолчанию и явно отражено в конфиге. Это 120 секунд и значение 3, а не только визуальный фикс.
- Настройки независимы: полное включение, зелёный preview, переопределение генерации, интервал, значения 120/3, диагностика.
- F10 перечитывает конфиг. Отключение возвращает захваченные в этой сессии предыдущие значения, если они всё ещё принадлежат моду. Уже изменённые другим кодом параметры не перезаписываются при откате.
- Ошибка функции отключает её с записью в лог; Harmony и обработчики запуска skyBREAK не затрагиваются.

Установка
1. Закройте игру.
2. Скопируйте исходный BepInEx\plugins\WTTG2_RemoteVPN_Green_BepInEx.dll в резервную копию за пределами plugins.
3. Замените его новой DLL с тем же именем.
4. После запуска настройки появятся в BepInEx\config\com.wttg2.remotevpn.greenfix.cfg.

Отключить переопределение генерации
В [ExistingBehavior] установите MaintainCurrencyOverride=false, затем F10 или перезапуск. Зелёный preview продолжит работать.

Откат
Закройте игру и замените новый DLL своей резервной копией. Сохранения и исходные игровые DLL этот пакет не меняет. Снимки для восстановления существуют только в памяти текущего запуска; предыдущие изменения старого мода до установки этой версии автоматически не реконструируются.

Проверка
Сборка выполнена против установленных Unity 2017.3/BepInEx 5.4.23.5 и игровых Managed DLL. Все использованные внешние поля/методы найдены. Все 11 методов прошли отдельную Mono JIT preparation без исполнения.
Standalone Mono не имеет нативных вызовов Unity; это не тест фактического preview/генерации в живой игре. Подтверждение игрового runtime указывается основным отчётом отдельно.
