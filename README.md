# Remote VPN Green Fix — Welcome to the Game II

VPN mod for Welcome to the Game II (WTTG2): green placement preview and adjustable DOSCoin generation.

**Скачать:** [готовые файлы 1.1.1](https://github.com/x1pee/wttg2-remote-vpn-green-fix/releases/tag/v1.1.1).

Переработка существующего Remote VPN Green Fix: кеширование объектов, проверка раз в секунду вместо поиска каждый кадр и MaterialPropertyBlock для зелёного предпросмотра.

Важно: прежнее переопределение генерации 120 секунд / 3 DOSCoin сохранено по умолчанию. Его можно отключить настройкой MaintainCurrencyOverride=false. Зелёный цвет не делает недопустимое место установки допустимым.

В версии 1.1.1 переопределение применяется только к установленным VPN. При подборе, повторной установке или перерасчёте игрой мод обновляет исходные значения для корректного отключения; пустые объекты из пула не изменяются. Неизменившиеся параметры повторно не записываются.

## Установка и использование

Скачайте ZIP из Releases. Закройте игру и скопируйте `WTTG2_RemoteVPN_Green_BepInEx.dll` в `BepInEx/plugins`. Запустите игру снова. Для отката удалите эту DLL при закрытой игре.

Замените прежний одноимённый DLL, сохранив его копию вне plugins. Две версии одновременно не устанавливайте. F10 перечитывает конфиг com.wttg2.remotevpn.greenfix.cfg. Для обычной генерации установите MaintainCurrencyOverride=false.

## Исходники и сборка

Сборка требует локальные игровые библиотеки и BepInEx 5.4.23.5; они не включены в репозиторий.

```powershell
.\build.ps1 -GamePath "D:\Games\Welcome to the Game II"
```

## Проверка

Сборка и используемые игровые поля/методы проверены; выполнены изолированные runtime-проверки с установленными соседними плагинами. Длительный обычный игровой сеанс не проверен.

`tests/run.ps1` проверяет 12 сценариев владения параметрами на тестовых заменах Unity/BepInEx, компилируя настоящий исходник плагина. Эти проверки не заменяют запуск игры и не обращаются к её файлам или сохранениям.

Подробности исправления 1.1.1 и границы проверки — в [AUDIT.md](AUDIT.md).

Проверено на Windows x64, Unity 2017.3. Для BepInEx-плагинов используется BepInEx 5.4.23.5. Совместимость с другими версиями игры не гарантируется.
